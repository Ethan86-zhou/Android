# 轻刷 LightSwipe · v0.5.0

使用中国大陆抖音官方网页的轻量 Android 浏览器。独立包名 `com.zhou.douyinlite`，不需要安装抖音原生 APP；账号、内容、推荐和播放权限由官网决定。

[安装包 LightSwipe-0.5.0-debug.apk](outputs/2026-10-14-v0.5.0-native-feed/LightSwipe-0.5.0-debug.apk)。使用手机系统 WebView，不把浏览器引擎重复打入 APK。实际 App 数据占用另计。

2026-10-14：精选频道改为原生单列列表——官网卡片的封面、标题、作者和点赞数只读镜像到原生界面，点卡片仍由官网真实节点打开详情，视频播放留在 WebView。不抓取接口、不读取视频地址、封面仅内存缓存且域名限定抖音系 CDN。抽取不可用时自动回退网页渲染，`⋯` 菜单可手动切换网页 / 原生列表。推荐频道与播放逻辑不变。

## 使用

- 顶部只显示原生“精选 / 推荐”两标签和右上角 `⋯`。精选默认显示原生单列列表（封面 + 标题 + 作者 + 点赞），点击卡片进入官网视频详情；推荐直接播放视频并上滑切换。
- `⋯` →“精选改用网页列表”可回到官网单列卡片渲染，随时可再切回；该选择会记住。原生列表不可用时（如官网改版）自动使用网页列表。
- 官网侧栏、搜索栏和精选分类条收起，内容铺满可用宽度。推荐视频使用固定视口，并校正网页每张视频的高度与间距，避免反复上滑后画面逐渐上移；精选保持单列浏览。
- 启动、刷新和切频道会保留目标频道，等待官网地址、布局与原生标签一致后再结束打开状态。网页首次可见时即应用精简布局；等待超过 15 秒显示轻提示，可点击重试。切频道使用官网原有导航，账号、推荐和视频仍由官网处理。
- 推荐和精选视频详情中，收起官网桌面播放栏，底部使用手机原生播放 / 暂停按钮与细进度条。独立底栏不覆盖视频，进度拖动触控区高度为 **44dp**；仅在拖动时显示目标时间和总时长，松手后收起。
- 进度条的灰色部分显示当前视频实际已缓冲到的位置；播放暂缺数据时显示“正在缓冲…”，恢复播放后收起。缓冲状态来自系统视频播放器，不额外下载或预取视频。
- 视频尚未取得有效时长或不支持跳转时，进度条不可拖动。松手只提交一次跳转；切换视频、网页跳转、退到后台、打开账号窗口、多点触摸或触摸取消会放弃本次拖动，避免误跳到下一条视频。拖动不额外改变播放 / 暂停状态或倍速。
- 视频左右边缘静止长按约 0.4 秒进入 2 倍速，松手恢复之前的倍率；长按后下滑锁定，点顶部速度按钮解除。锁定后继续上滑可换视频。顶部标签和底部进度条不触发该手势。
- 普通滑动交给官网。切到后台、触摸取消、多点触摸、网页跳转会解除加速；后台暂停视频。
- 正常播放时不显示倍速按钮；加速时在画面上方显示临时提示，锁定后点提示解除。
- 右上角 `⋯` 提供刷新、手势说明、缓存统计和清理。固定竖屏，视频播放时保持屏幕亮。
- 登录或管理账号：`⋯` →“登录 / 账号”恢复完整官网界面及原网页播放控件，同时收起原生底栏；完成后选“返回精简界面”或点击任一频道。官网登录弹窗保持原界面。本 App 不复制 Chrome 的账号状态，也不读取密码；登录 Cookie 与站点存储仅存在应用私有空间。

## 缓存控制

允许官网按 HTTP 缓存规则复用网页和视频资源，WebView 与 Service Worker 使用 `LOAD_DEFAULT`。不下载或另存视频副本，不承诺离线播放；缓存复用取决于官网响应、视频传输方式和当前授权，官网自身可能预加载内容。

**1 GiB（1024 MiB）仅作为空间提醒线，不触发 App 自动清理。** 资源缓存由 WebView 自身管理；App 不会因为超额、暂停、暂时没有播放或切到后台而整批清空，避免干扰后续缓冲和续播。

后台持续安静 8 秒，或前台空闲 15 秒后，可以进行只读大小统计；播放、缓冲、页面加载时暂缓统计，自动扫描最多每 2 分钟一次。统计过程只读取文件元信息，不删除资源文件。

设置页的统计请求会合并，15 秒内复用快照。用户主动点击“清理缓存”仍立即请求清理，旧快照随即失效，稍后重新统计；回调数值是请求之后的观察值，不代表引擎异步删除已经全部完成。

1 GiB 不是整个 App 数据的硬上限；超过时在缓存设置中提示，由用户决定是否手动清理。手动清理通过系统 WebView 完成，不直接删除活跃缓存库；这不是按单个视频淘汰的自建 LRU，主动清理后部分资源需要重新缓冲。

“清理缓存”保留 Cookie、Local Storage、IndexedDB 等登录与网站数据。统计中的“网站及 WebView 数据”单独列出，不包含在缓存阈值中；如站点数据持续增长，可在设置中明确确认“重置网站数据”，这会退出本 App 登录。不会影响 Chrome 或轻听。

本 App 不修改抖音资源授权，不抓取接口或导出视频，不添加广告或分析 SDK，仅申请网络权限。禁止文件访问和明文 HTTP；备份关闭。

## 构建

JDK 17、Gradle 8.10.2、AGP 8.7.3、compileSdk / targetSdk 36、minSdk 26。配置本机 `JAVA_HOME`、`ANDROID_HOME`，使用本项目 Wrapper：

```powershell
.\gradlew.bat assembleDebug lintDebug
```

只有 Android framework 依赖，系统 WebView 由手机提供。调试版开放 WebView 调试，发布版关闭。不要将调试接口转发到外部网络。
