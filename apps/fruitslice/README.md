# 果刃 FruitSlice

离线横屏切水果小游戏，打开直接开局。滑动手指切开水果，避开炸弹；彩虹果实随机切换限时玩法。本机保存成绩历史，没有账号、联网、广告、内购或设置页面。全部图形与音效为本项目制作。

包名：`com.ethan.fruitslice`。最低 Android 16 / API 36，版本 `1.1.0`。按用户要求，以当前连接的三星 SM-S9080（Android 16）作为最低支持系统。

## 开始玩

安装 [`FruitSlice-1.1.0-debug.apk`](outputs/2026-10-11-v1.1.0/FruitSlice-1.1.0-debug.apk)，打开“果刃”直接进入横屏切台，不经过账号、菜单或设置。支持向任意方向快速划动与多指操作，水果会被切成两半，伴随刀光、果汁、短音效和系统触感。

西瓜、橙子、猕猴桃、苹果、菠萝、李子使用明亮的写实果皮和果肉贴图，素材随 APK 离线提供；完整水果和切开的两半均保持实际尺寸。切割后的飞散果汁短暂消失，木板上不保留果汁染色或残留色块。素材来源与生成提示见 [美术素材说明](docs/artwork.md)。

- 每局 60 秒，普通水果随机混合四种大小，最小直径为最大直径的 1/4。由大到小基础得分为 5、8、12、20 分，越小越难切、得分越高。一刀切中至少 3 个水果时，每个再奖励 2 分，双倍模式同时翻倍基础分与连击奖励。
- 炸弹扣 10 分和 3 秒，分数最低为 0。经典、冰封和双倍模式漏掉 3 个普通水果结束本局；漏掉彩虹果实不扣分。
- 发光的彩虹星形果实在开局约 2.2 秒出现，之后约每 9–13 秒出现。切中会随机选择与当前不同的一种特殊玩法，持续 8–12 秒；结束后回到经典。
- 右上角时钟打开历史，双竖线暂停；暂停卡片只提供继续和历史。切到后台、展开通知栏或失去窗口焦点时暂停，回来后点“继续开切”。结算后直接“再来一局”。

| 特殊玩法 | 效果 |
| --- | --- |
| 水果狂热 | 密集水果、没有炸弹、漏果不惩罚 |
| 冰封时刻 | 水果运动速度降低，关卡倒计时正常走动 |
| 双倍刀锋 | 水果得分和连击奖励翻倍 |
| 禅意切台 | 没有炸弹、漏果不惩罚，保持常规节奏 |

安全模式结束时，已抛出的水果继续免除漏果处罚，防止切换瞬间产生不公平惩罚。

| 水果大小 | 直径比例 | 基础得分 |
| --- | --- | --- |
| 大 | 1 | 5 |
| 中大 | 3/4 | 8 |
| 中小 | 1/2 | 12 |
| 小 | 1/4 | 20 |

各类普通水果都可以出现不同尺寸。开场首波同时出现大果和小果；判定使用各自实际半径，不给小果套大果的碰撞范围。彩虹果实和炸弹仍采用固定尺寸及原有规则。

## 本机记录

只保存得分最高的 10 局，按分数从高到低排列；同分优先保留较新的一局，时间也相同则按固定的局 ID 排序。每条包含分数、切果数、最高连击、漏果、炸弹、换模式次数、时长与结束原因。升级时自动从旧记录中筛选前 10 局并立即保存，终身最高分独立保留。完成一局后参与高分榜筛选；未进入前 10 的成绩不留在历史中。进行中的一局每 5 秒及暂停时保存恢复点，进程被关闭后，下次启动把该恢复点记作“中断保存”参与筛选并开始新局。

数据存放在应用私有 SharedPreferences，不申请网络、外部存储或传感器权限。关闭云备份与设备迁移。相同签名覆盖安装保留记录；卸载会清除数据，不用卸载解决签名不一致问题。

## 构建

本项目保留独立 Wrapper，没有外部运行时依赖。使用 JDK 17 或 Android Studio JBR、Android SDK Platform 36 和 Build Tools 36.0.0；AGP 8.9.1、Gradle 8.11.1。SDK/JDK 与签名密钥按本机配置，`local.properties` 不提交。Android 16 工具版本要求见 [Android 官方文档](https://developer.android.com/build/releases/about-agp)。

```powershell
# 在此 APP 目录下，JAVA_HOME 使用本机实际 JDK 路径。
.\gradlew.bat --no-daemon assembleDebug assembleDebugAndroidTest lintDebug
.\tools\check-engine.ps1
python .\tools\device_acceptance.py --serial <设备序列号> --output .\outputs\<新的验证目录>
```

`device_acceptance.py` 使用 Python 标准库，默认从本机 Android SDK 找 ADB，也可用 `--adb` 指定。验证目录必须是全新或空目录，防止覆盖旧证据。安装失败时保留手机数据并检查签名，不自动卸载。设备测试运行器只放在单独的测试 APK，交付游戏包不包含场景注入功能；完整玩法验收后恢复测试前的记录及最高分，并按当前前 10 规则筛选。添加 `--history-only` 只验证存储规则、旧数据升级和实际触摸打开高分榜，不向用户记录写入虚构成绩。

`GameEngine.java` 是纯 Java 规则与物理；`GameView.java` 绘制界面并处理触摸和生命周期；`GameArt.java` 缓存原创图形；`GameAudio.java` 在私有缓存生成原创音效；`HistoryStore.java` 保存成绩和检查点。debug 版本额外提供私有 `files/debug_state.json` 便于复核，用户界面没有调试入口。
